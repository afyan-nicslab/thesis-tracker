# Thesis Tracker

Aplikasi web pribadi untuk memantau perjalanan tesis S2, dari concept note sampai Sidang: persiapan, penulisan per bab dan subbab, masukan pembimbing, serta syarat administrasi.

**Alamat:** https://afyan-nicslab.github.io/thesis-tracker/ (bisa dipasang sebagai aplikasi di HP dan laptop)

Semua data tinggal di Google Sheet yang tidak publik dan hanya bisa dibaca setelah masuk. Repo ini hanya berisi kode dan dokumen.

## Dokumen

- [PRD](docs/PRD.md): apa yang dibangun
- [ARCHITECTURE](docs/ARCHITECTURE.md): bagaimana bagian-bagiannya bekerja
- [DESIGN-SYSTEM](docs/DESIGN-SYSTEM.md): tampilan dan komponen
- [AGENTS](AGENTS.md): aturan untuk asisten AI yang ikut mengerjakan repo ini
